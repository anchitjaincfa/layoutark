# Privacy

LayoutArk has no accounts, file uploads, analytics, advertising trackers, or document backend.

The estate tool reads a manifest you select using browser APIs. Analysis happens in the current browser tab. Refreshing clears the imported manifest. LayoutArk never asks for or reads the contents of Publisher files.

A manifest can contain paths and filenames. Treat it as sensitive and do not share it publicly. The scanner replaces the current user profile root with `%USERPROFILE%` by default.
